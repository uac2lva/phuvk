# 🛂 Чек-лист документів для оформлення закордонного паспорта в ЗДУ

## 📌 Про проєкт

Інтерактивний вебзастосунок (Single Page Application) для громадян України, який допомагає точно визначити вичерпний персональний перелік документів, вартість та додаткові вимоги для оформлення закордонного паспорта в закордонних дипломатичних установах (посольствах та генеральних консульствах).

Проєкт базується на актуальному законодавстві:

* **Закон України № 5492-VI** («Про Єдиний державний демографічний реєстр...»).
* **Порядок КМУ № 152** (включаючи останні зміни за ПКМУ № 1709).

## 🚀 Реалізований функціонал (v2.8)

### 🎨 Дизайн, UI/UX та Доступність

* **Стилістика «Дії»:** Чистий, мінімалістичний інтерфейс із великими читабельними шрифтами, картками результатів та блоками попереджень.
* **Smart-інпути:** Введення чисел (наприклад, віку) відбувається без втрати фокуса курсора, а системні стрілочки (spin-buttons) приховані для кращого вигляду.
* **Сегментовані кнопки:** Замість довгих випадаючих списків чи радіокнопок із текстом використовуються зручні цифрові плитки-кнопки (`[0]`, `[1]`, `[2]`).
* **Інклюзивність (WCAG AAA):** Кольорова палітра та контрастність блоків розраховані на комфортне сприйняття особами з будь-якими формами дальтонізму.
* **Універсальність:** Застосунок не прив'язаний до конкретного Посольства і може використовуватися будь-якою ЗДУ.

### 🧠 Бізнес-логіка опитування

* **Динамічна фільтрація:** Питання з'являються поступово залежно від попередніх відповідей (наприклад, питання про дієздатність з'являється лише для осіб 14+).
* **Мета звернення:** Чіткий поділ на перше оформлення, заміну втраченого/викраденого та обмін (із вибором 4 законних підстав для обміну).
* **Калькуляція паспортів:** Точний облік кількості дійсних та прострочених паспортів (з роз'ясненням, що паспорти, анульовані з проколом, не враховуються).
* **Специфічні кейси:** Враховуються правила для дітей-сиріт, громадянство батьків на момент народження, звільнення від сплати консульського збору (6 категорій) та необхідність виїзного обслуговування.

### 📄 Формування результатів

* **Порядок документів:** Список генерується не системно, а в логічній послідовності консульського прийому (спершу е-ВОД, потім паспорт для обміну, внутрішній паспорт, документ про проживання, підстави обміну, фото, оплата і старі паспорти для знищення).
* **Військовий облік (18–60 років):** Виводиться жорстка вимога щодо наявності е-ВОД із QR-кодом (через застосунок «Резерв+» або «Дія») із вказівкою надіслати PDF на e-mail консульства.
* **Перевірка 2 дійсних паспортів:** Вбудований блокер — якщо в заявника вже є два дійсних закордонних паспорти, система попереджає, що один із них доведеться обов'язково здати під час подання документів.
* **Оплата та пільги:** Якщо обрано пільгу, система просить надати оригінал посвідчення та сплатити лише 37 € за розгляд. У стандартному кейсі виводиться повна сума (120 €) через POS-термінал.
* **Без копій:** Акцент зроблено виключно на наданні оригіналів документів.
* **Іноземні документи:** Надається попередження про необхідність Апостиля/легалізації та нотаріального перекладу (з окремим правилом для Латвії).
